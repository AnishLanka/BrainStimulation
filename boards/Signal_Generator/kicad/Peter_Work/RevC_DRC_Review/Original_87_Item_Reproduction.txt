Cause established:
The complete project's .kicad_dru contains a 0.18 mm pad-to-pad rule restricted
to U4/U7. It permits the recovered source footprint's 0.1928 mm gap. The project
also defines normal 0.2 mm and cross-domain 3.5 mm spacing. Removing project
context removes those rules and the local-library binding. A zero result with
the complete project therefore did not imply zero DRC for a standalone board.

Requested correction is owned by the parent task: eliminate the U4/U7 special
clearance rule by matching TI's 1.4 x 0.45 mm VSSOP land geometry, then package
the complete native project and rerun DRC. This reproduction is a baseline,
not validation of that subsequently modified board.
